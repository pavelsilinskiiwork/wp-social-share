Lightweight social share buttons for WordPress. No external scripts, no tracking, GDPR-friendly.

== Description ==

Pavel Silinskii Social Share adds beautiful, lightweight share buttons to your WordPress posts and pages.

Features:

* 5 networks: Facebook, Twitter/X, LinkedIn, Pinterest, WhatsApp
* Copy Link button with clipboard support
* 3 button styles: Icon + Text, Icon only, Text only
* 3 shapes: Rounded, Square, Circle
* 3 sizes: Small, Medium, Large
* Placement: before content, after content, both, or manual via shortcode [psss_share]
* Works on any post type
* No external scripts — no jQuery, no CDN, no tracking
* GDPR-friendly — no data collected, no cookies set

== Installation ==

1. Upload plugin files to /wp-content/plugins/pavel-silinskii-social-share/
2. Activate through the Plugins screen.
3. Go to Settings → Social Share to configure.

== Frequently Asked Questions ==

= Does it show share counts? =

Not in v1.0.0. Counts require API calls which affect page speed.

= Is it GDPR compliant? =

Yes. No cookies, no data collection, no external requests on page load.

= Can I place buttons manually? =

Yes. Use shortcode [psss_share] anywhere.
